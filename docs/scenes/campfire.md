> **Catalogue status:** WIP scene record derived from the 123mikeyd NRCU Vault.

## Recorded scene

The NRCU description places the Hermes Agent Squad around a campfire in a dark, silhouetted forest beneath a starry sky and a large textured moon. Warm orange firelight contrasts with the blue night. The source says each member roasts marshmallows while carrying or using a signature item.
