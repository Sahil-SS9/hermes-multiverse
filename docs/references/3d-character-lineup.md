> **Catalogue type:** shared 3D model reference, not a story scene or a complete labelled roster.

## Source context

Upstream commit [`5414f1ac`](https://github.com/123mikeyd/nrcu-vault/commit/5414f1ac6e770e7048622441556bad731dcf3270) added this full-size Blender-style lineup below the NRCU gallery. The same readme section links rigged-model downloads for Doge Man, Teknium, Turbo Fit and Witcheer.

## What the image establishes

Direct inspection shows many static 3D models arranged on a dark modelling grid. The lineup includes recognisable designs corresponding to Doge Man, Teknium, Turbo Fit and Witcheer, alongside numerous other humanoid, animal and creature models.

No identity labels appear in the image. It must therefore not be used as proof that every visible model maps to a named Hermes Multiverse character, belongs to the squad, or has an approved design. Only the four characters tied to the upstream release table are linked in the canonical asset record.
