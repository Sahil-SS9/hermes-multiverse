# Hermes Multiverse — NRCU Community Character Archive

> Work in progress: 33 evidence-bounded character records and 277 approved style-sheet previews.

![Sahil anime style-sheet preview](previews/sahil/anime.webp)

Hermes Multiverse is an unofficial, fan-made archive of community character designs, style studies, scenes, and production notes associated with the Hermes Agent community. It is not an official Nous Research project.

## Origin and credit

This collection builds on the documentation foundation of **[123mikeyd's NRCU Vault](docs/characters/123mikeyd.md)**. The original 17-profile archive, scene notes, music-video records, and content-rights boundary were expanded into a current 33-character manifest-backed catalogue. See [ATTRIBUTION.md](ATTRIBUTION.md) for the complete public register.

## Release snapshot

- 33 character documentation records
- 277 approved style-sheet previews
- 9 target styles, with explicitly documented pending work and omissions
- 4 scene documents and 3 music-video documents
